# visit.bohemiabio.cz

This repository is configured for GitHub Pages and serves a static redirect page.

## Redirect target

Edit `index.html` and change the URL in:

- `<meta http-equiv="refresh" ...>`
- `<link rel="canonical" ...>`
- `window.location.replace(...)`
- fallback `<a href="...">`

## Domain

The custom domain is configured in `CNAME` as:

`visit.bohemiabio.cz`
